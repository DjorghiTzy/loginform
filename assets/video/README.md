# Folder Video

Taruh file video HD kamu di folder ini dengan nama:

- `background.mp4`  ← WAJIB (format utama, paling kompatibel)
- `background.webm` ← opsional (biar lebih ringan di Chrome/Firefox)

Halaman otomatis memakai file tersebut sebagai background layar penuh.
Kalau file belum ada, halaman tetap normal dan memakai gradien langit malam sebagai cadangan.

Saran biar lancar di Vercel:
- Resolusi 1920x1080 (Full HD), durasi 10-30 detik (looping)
- Ukuran file sebaiknya di bawah 25 MB (limit file Git biasa 100 MB)
- Video tanpa audio (halaman ini memutar secara muted)
